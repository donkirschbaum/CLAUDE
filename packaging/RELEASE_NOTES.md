**LoopTape: Tape Echo + Layer Looper** für macOS (VST3 + Audio Unit, Universal: Apple Silicon + Intel, macOS 11+)

**Neu in 1.2.0**
- **HOST** ist jetzt im **Looper**: Aufnahme startet auf dem nächsten Takt, der Loop bleibt an Abletons Songposition, Tempo und Play/Stop gekoppelt
- **TAKTE**: Loop-Länge wählbar: 1, 2, 4, 8 oder 16 Takte (nimmt genau so viele Takte auf und spielt dann automatisch) oder Frei
- **Export = komplette Looper-Ausgabe**, inkl. ½ Speed, Reverse, Loop Level und Echos bei „Feed Delay“
- Tape Echo: Delay-Zeit wieder frei einstellbar (der Delay-Sync aus 1.1 ist entfallen)

- **`.pkg`** = Installer (empfohlen). Falls macOS blockiert: Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“.
- **`.zip`** = Plugins + `Install.command` für die manuelle Installation.

Anleitung und Return-Spur-Workflow: siehe [README](https://github.com/donkirschbaum/CLAUDE/tree/looptape#readme).
