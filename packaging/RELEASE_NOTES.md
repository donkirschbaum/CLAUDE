**LoopTape: Tape Echo + Layer Looper** für macOS (VST3 + Audio Unit, Universal: Apple Silicon + Intel, macOS 11+)

**Neu in 1.1.0**
- **HOST**-Button: Delay synchron zum Ableton-Tempo, mit Anzeige von BPM und resultierender Delay-Zeit
- **EXPORT WAV**: Loop als WAV speichern (Mix oder alle Layer einzeln)
- **LOOP INS SET ZIEHEN**: Loop per Drag & Drop direkt auf eine Ableton-Spur

- **`.pkg`** = Installer (empfohlen). Falls macOS blockiert: Systemeinstellungen → Datenschutz & Sicherheit → „Dennoch öffnen“.
- **`.zip`** = Plugins + `Install.command` für die manuelle Installation.

Anleitung und Return-Spur-Workflow: siehe [README](https://github.com/donkirschbaum/CLAUDE/tree/looptape#readme).
